# Factor Scoring + Checklist Implementation Plan (compact)

> Execute inline, TDD. Spec: `docs/2026-10-25-factor-scoring-spec.md` (S1-S20) plus profile decisions in `docs/2026-10-25-price-history-and-profile-spec.md`.

**Goal:** Reproducible 0-100 factor scores and a 9-point checklist from Facts, ranked inside a universe, with weights from the user's profile and tests that catch bad data moving ranks.
**Architecture:** `data/score_metrics.json` (versioned, reviewed) -> `scoring.py` pure functions over `dict[ticker, FactSet]` -> score Facts -> renderer SCORECARD section. `universe.py` builds FactSets for a ticker list with a 1-day disk cache. No LLM.
**Constraints:** no imputation; coverage >= 60% per factor; >= 2 valid factors else abstain; winsorise 5/95 when >= 10 valid values; percentile rank 0-100; ties alphabetical; stale (> 7 days retrieved) and not-yet-public facts excluded; every score cites input fact_ids and the config hash; runtime warns on overdue review, tests fail.
**Deferred (ruled):** sector-relative grouping and bank metric set (need a sector field; S13, S14), momentum beyond price facts, goal/liquidity use.

## Tasks
1. `score_metrics.json` + `load_score_config(path, today, strict)` + validation (S3). Metrics: value {pe_ttm lower valid 0<x<=75; pb lower 0<x<=50}, quality {roe higher -1<x<1.5; net_margin_q higher -1<x<1; debt_to_equity lower 0<=x<=20}, growth {net_income_yoy higher -5<x<10; revenue_yoy higher -1<x<5}, momentum {return_1y higher -0.95<x<10; relative_return_1y higher -2<x<10; pct_from_52w_high higher -1<=x<=0}, risk {volatility_1y lower 0<x<3; max_drawdown_3y higher -1<=x<=0; beta_1y lower 0<x<4}.
2. `extract_metrics(factset, as_of, now, max_age_days)` (S12, S19) and `score_universe(factsets, weights, config, as_of, now)` (S1, S4-S11, S17, S20); `ScoreResult`; `rank_diff` (S15).
3. `score_facts(result)` provenance (S16) + `checklist(factset)` 9 tests with pass/fail/unavailable (C1-C6).
4. `universe.py` (ticker file, cache) + CLI `--universe FILE` + render SCORECARD with disclaimer (S18).
