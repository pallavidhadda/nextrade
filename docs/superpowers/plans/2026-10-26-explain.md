# Explanation layer plan (compact)
T1 `indiafacts/digest.py`: `build_digest(fs, scorecard, profile) -> Digest(text, ids: dict[short->fact_id|label], est_tokens, dropped)`; `est_tokens(text)`; shrink to budget deterministically.
T2 `indiafacts/explain.py`: `template_explanation(digest, scorecard, checklist) -> Explanation`; `triggers(scorecard, fs) -> list[Trigger]`; models Claim/Explanation.
T3 validation `validate_llm_output(raw, digest) -> (Explanation|None, removed, reasons)`; advice-word and number checks.
T4 cache + token log: `LLMCache` (hash of model, prompt version, digest), `TokenLog` append-only JSONL, `token_report()`.
T5 providers: `LLMClient` protocol; `GeminiClient`, `OpenAICompatClient`, `AnthropicClient` over injectable `post(url, headers, json)`; `explain(digest, provider, cache, log) -> Explanation` with fallback.
T6 wiring: CLI `--explain [template|llm]`, `--llm gemini|openai|anthropic`, `--llm-model`; render terminal EXPLANATION block and HTML card; token line.
