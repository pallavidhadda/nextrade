# Test plan (written before building) — India fundamentals layer
Framework: pytest. Network tests marked `live` and excluded from default run; everything else uses recorded fixtures.

## Unit — point-in-time
T1 Q1–Q3 period: as_of = period_end+44d excludes it; +46d includes it.
T2 Year-end period: as_of = +59d excludes; +61d includes.
T3 A real filing date (override) earlier than deadline makes it available on that date.
T4 as_of before all periods -> empty set + "no data" line, never an exception.
T5 Output flags "availability approximated" when no real filing date used.

## Unit — data integrity
T6 Missing line item -> metric null with reason; digest says "No data for: X".
T7 Never emit a number not present in the StatementSet (property test over random sets).
T8 Currency INR preserved; crore/lakh display conversion round-trips.
T9 Basis label (consolidated/standalone/unknown) carried to every metric; mixed basis raises a warning.
T10 Bank ticker (HDFCBANK.NS fixture) skips EBITDA/EV metrics and says why.
T11 Renamed/delisted ticker fixture (empty Yahoo) -> `unavailable` with reason, no filler text.
T12 .NS and .BO normalisation; invalid ticker with path characters rejected.

## Unit — metrics and checks
T13 Growth, margin, D/E, interest cover, FCF match hand-calculated values on a fixture.
T14 Division by zero / negative equity -> null with reason.
T15 cross_check: 10% apart passes, 20% apart warns, fields with differing definitions are skipped.

## Budget and cost
T16 Digest for RELIANCE.NS fixture <= 600 tokens (tokenizer estimate, 10% tolerance).
T17 Same prompt twice -> second LLM call served from cache (0 network calls) [M3].
T18 Throttle: 20 calls never exceed 15 per rolling minute with a fake clock [M3].

## Safety / product
T19 Every digest, report and UI page contains the not-advice disclaimer.
T20 Risk clamp never increases a position; each clamp logged [M2].
T21 No API key appears in logs, cache files or exported reports.
T22 Router: .NS ticker uses india_fundamentals; US ticker still uses SEC EDGAR path (regression).

## Acceptance (replay)
A1 RELIANCE.NS run dated today: fundamentals digest contains >= 8 cited numbers with period + source, zero unsupported claims.
A2 Same ticker dated 2026-10-23: no longer wholesale-withheld; shows periods available by that date, labelled approximate.
A3 TATAMOTORS.NS style failure: report states data unavailable; final rating text does not claim "strong fundamentals".
A4 Token total for 2-analyst run recorded and compared with 39k baseline.
