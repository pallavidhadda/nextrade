# Evidence-linked explanation layer: spec (compact)
Research/education only; not financial, investment or trading advice.
Goal: turn the facts, scores, checklist and peers into a short plain-English explanation with MINIMUM tokens. The LLM only narrates numbers the code already computed; code checks every claim; with no LLM the app still produces a deterministic explanation.
Token targets (proposals, to be measured): digest <= 1,500 estimated tokens in, <= 450 tokens out, one call per report, cached by input hash (repeat = 0 tokens). Baseline to beat: TradingAgents run, 39k tokens for 13 calls.
Pipeline: digest (short ids F1.., every number with its status; gaps listed explicitly) -> template explanation (deterministic, always available) -> optional LLM call returning strict JSON {summary, claims[{type fact|inference|hypothesis, text, ids}], uncertainty} -> validation (ids exist, every number in the text appears in the digest, no advice words, JSON valid) -> invalid claims dropped; fewer than 2 valid claims or any provider error = fall back to the template with a notice.
Triggers ("what would change the picture") are computed in code from failed or unavailable checklist items and weak factors, each with a numeric threshold and fact id; the LLM never invents them.
Providers behind one interface: none/template (default), Gemini (free tier, REST), OpenAI-compatible (Ollama, LM Studio, OpenRouter), Anthropic. Keys only from the environment; never in prompts, cache or logs. In Claude Code the plugin can skip the provider and let Claude read the digest directly (zero API tokens).
Safety: company names and other free text are length-limited and stripped of control characters, passed as JSON data with a system rule to treat them as data; output rejected if it contains buy/sell/recommend/target-price language.
Tests EX1-EX16: digest deterministic and within budget; gaps always present; template deterministic with ids and uncertainty and no advice words; claim ids must exist; invented numbers dropped; advice words rejected; cache hit/miss/corrupt; provider failure falls back; token log and budget shrink; triggers deterministic with thresholds; no key leakage; prompt-injection neutralised; adapter request/response shapes with fake HTTP; render in terminal and HTML with type badges and model label; CLI flags.
